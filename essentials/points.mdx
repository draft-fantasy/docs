You can view scoring options for your league by visiting the `Settings` page for your league. You can find a link to this page on the dashboard.
The default scoring system is shown below but you can customise to your needs.

### Default scoring for Premier League

| Stat             | Goalkeeper     | Defender       | Midfielder | Forward|
|------------------|----------------|----------------|----------|----------|
| \<60 mins played | 1              | 1              | 1        | 1        |
| 60+ mins played  | 2              | 2              | 2        | 2        |
| Goal scored      | 10             | 6              | 5        | 4        |
| Assist           | 3              | 3              | 3        | 3        |
| Goal conceded    | -1 per 2 conceded | -1 per 2 conceded | 0  | 0        |
| Clean sheet      | 4              | 4              | 1        | 0        |
| Yellow card      | -1             | -1             | -1       | -1       |
| Red card         | -3             | -3             | -3       | -3       |
| Save             | 1 per 3 saves  | 0              | 0        | 0        |
| Own goal         | -2             | -2             | -2       | -2       |
| Penalty missed   | -2             | -2             | -2       | -2       |
| Penalty saved    | 5              | 0              | 0        | 0        |
| Defensive contributions | 0       | 2 pts per 10, 2-pt cap | 2 pts per 12, 2-pt cap | 2 pts per 12, 2-pt cap |
| Bonus points     | 1-3            | 1-3            | 1-3      | 1-3      |

### Fantasy assists

The **Premier League counts FPL fantasy assists**. These can be awarded for more than the final pass before a goal — for example, when a player wins a penalty that is scored, or when a teammate scores after the player's shot is blocked, saved or hits the woodwork.

The **World Cup also counts fantasy assists** as a special exception.

**All other games count only official assists**, meaning the final pass or touch that directly leads to a goal. They do not award fantasy assists for blocked shots, rebounds or penalties won.

## Custom scoring

To change the scoring system, visit the league `Settings` page, click `Edit`, and then click `Edit Custom Scoring`.

You will need to be the league admin to make changes.

As you edit values, a live preview shows how your changes would affect real player points, so you can check the impact of your scoring system before saving.

### Available stats

You can set the points awarded for each of the following, separately for each position:

- **Appearance and attacking**: minutes played (under 60, and 60 or more), goal scored, assist, expected goal (xG), expected assist (xA).
- **Goalkeeping and defending**: goal conceded (per number conceded), expected goals conceded, clean sheet, save (per number of saves), penalty saved, defensive contribution (with its own threshold and cap), tackle, interception, block, clearance.
- **Discipline**: yellow card, red card, own goal, penalty missed, foul committed, foul won, dispossession.
- **Passing and creativity**: pass, accurate pass %, key pass, cross, big chance created.
- **Shooting and duels**: shot on target, shot off target, aerial won, touch, dribble.
- **Bonus**: BPS and Bonus multipliers, and the Kante rule (points per set number of tackles and interceptions).

### Data availability by competition

Not every stat is recorded in every competition, because different games use different data sources:

- The **Premier League** uses official FPL data. It supports BPS, Bonus points, Defensive contributions and expected stats (xG, xA, expected goals conceded), but not the individual match events such as key passes, crosses, tackles, dribbles or shots.
- **Other competitions** (La Liga, Serie A, Bundesliga, Ligue 1, MLS, Brazil, the Champions League and the World Cup) use a detailed match-stats provider. They support passing, pass accuracy, tackles, interceptions, blocks, dribbles, shots, fouls and cards, but not BPS, Bonus points or Defensive contributions.

BPS, Bonus points and Defensive contributions are hidden from the scoring editor in competitions that do not support them. Any other stat your competition does not record simply scores zero, even if it still appears in the editor.

### Defensive contributions

A defensive contribution is a combined total of defensive actions recorded for one player in one match:

| Player position | Actions that count | Default award |
|-----------------|--------------------|---------------|
| Goalkeeper | None | No points |
| Defender | Clearances, blocks, interceptions and tackles | 2 points at 10 contributions |
| Midfielder or forward | Clearances, blocks, interceptions, tackles and ball recoveries | 2 points at 12 contributions |

A ball recovery is counted when a player wins or collects the ball and secures possession for their team. Recoveries count for midfielders and forwards, but not for defenders.

The default award is calculated separately for each match and is capped at 2 points. For example, a defender with 20 contributions still receives 2 points, not 4.

You can change this using three custom scoring fields:

- `Defensive contribution` is the number of points awarded each time the threshold is reached.
- `Per no of defensive contributions` is the threshold.
- `Max points from defensive contributions` is the most a player can receive in one match. Set it to `0` for no cap.

For example, settings of `2`, `10` and `2` award 2 points at 10 contributions, with a maximum of 2 points per match.

### Accurate pass percentage

The `Accurate pass %` custom scoring field has no percentage threshold or minimum number of attempted passes. It awards the value you enter for every percentage point of a player's recorded pass completion in that match.

For example, if you set it to `0.1` and a player completes 84% of their passes, they receive 8.4 points. Setting it to `1` would award 84 points. This field cannot currently award a one-off number of points for reaching a chosen percentage.

This is separate from pass completion in the Bonus Points System (BPS). BPS requires at least 30 attempted passes and uses the 70%, 80% and 90% bands shown below.

### Bonus points

1-3 points are awarded to the players that receive the most BPS (Bonus Points System) in a match.

Bonus point ties are resolved as follows:

- If there is a tie for first place, Players 1 & 2 will receive 3 points each and Player 3 will receive 1 point.
- If there is a tie for second place, Player 1 will receive 3 points and Players 2 and 3 will receive 2 points each.
- If there is a tie for third place, Player 1 will receive 3 points, Player 2 will receive 2 points and Players 3 & 4 will receive 1 point each.

BPS is calculated as follows:

| Action | BPS |
|--------|-----|
| Playing 1 to 60 minutes | 3 |
| Playing over 60 minutes | 6 |
| Goalkeepers and defenders scoring a goal | 12 |
| Midfielders scoring a goal | 18 |
| Forwards scoring a goal | 24 |
| Assists | 9 |
| Goalkeepers and defenders keeping a clean sheet | 12 |
| Saving a penalty | 9 |
| Save | 2 |
| Successful open play cross | 1 |
| Creating a big chance (a chance where the receiving player should score) | 3 |
| For every 2 clearances, blocks and interceptions (total) | 1 |
| For every 3 recoveries | 1 |
| Key pass | 1 |
| Successful tackle (net*) | 2 |
| Successful dribble | 1 |
| Scoring the goal that wins a match | 3 |
| Goalline clearance | 3 |
| Foul won | 1 |
| Shot on target | 2 |
| 70 to 79% pass completion (at least 30 passes attempted) | 2 |
| 80 to 89% pass completion (at least 30 passes attempted) | 4 |
| 90%+ pass completion (at least 30 passes attempted) | 6 |
| Goalkeeper/defender conceding a goal | -4 |
| Conceding a penalty | -3 |
| Missing a penalty | -6 |
| Yellow card | -3 |
| Red card | -9 |
| Own goal | -6 |
| Missing a big chance | -3 |
| Making an error which leads to a goal | -3 |
| Making an error which leads to an attempt at goal | -1 |
| Being tackled | -1 |
| Conceding a foul | -1 |
| Being caught offside | -1 |
| Shot off target | -1 |

#### Enabling or disabling bonus points in custom scoring

If you want bonus points on, then keep it set to 1-1-1-1 in the custom scoring system.
If you want bonus points off, then set it to 0-0-0-0.

You can leave BPS as is with 0-0-0-0, unless you want to award points for BPS scored.

If you were to set Bonus to 2-2-2-2, then players would receive 2/4/6 points as bonus points.
If you were to set BPS to 1-1-1-1, and a player scores 30 BPS, then they'd be awarded 30 points.

### Kante Points

We added the Kante rule to award players like N'Golo Kanté that are critical in a match, but typically do not score well in fantasy football.
Where N'Golo Kante would excel is tackles and interceptions, but in the default scoring system this stat does not earn any points.
You can award players points for interceptions and tackles, but when we originally introduced Kante Points, this was not an option.
For managers that prefer to use the original Kante points rules, we have added a setting to the scoring system for this.

The Kante points rule would award 1 point for every 2 tackles and/or interceptions for midfielders and forwards.

To set this, you can set `Tackle/Interception` to 1 and `Per no of tackles/interceptions` to 2 for midfielders and forwards.
So it should look like this:

| Player position | Tackle/Interception | Per no of tackles/interceptions |
|-----------------|---------------------|------------------------------|
| Goalkeeper      | 0                   | 0                            |
| Defender        | 0                   | 0                            |
| Midfielder      | 1                   | 2                            |
| Forward         | 1                   | 2                            |

Of course, you can adjust these values to your liking.
