In a snake draft, managers pick players one at a time.
You can pick any unpicked player as long as the player fits into the squad constraints for the league.

Each round, the pick order is reversed. Hence the name "Snake Draft".

The order in a 5 person snake draft is as follows:

**Round 1**:

* Manager 1 picks a player.
* Manager 2 picks a player.
* Manager 3 picks a player.
* Manager 4 picks a player.
* Manager 5 picks a player.

**Round 2**:

* Manager 5 picks a player.
* Manager 4 picks a player.
* Manager 3 picks a player.
* Manager 2 picks a player.
* Manager 1 picks a player.

**Round 3**:

* Manager 1 picks a player.
* Manager 2 picks a player.
* Manager 3 picks a player.
* Manager 4 picks a player.
* Manager 5 picks a player.

And so on. The draft ends when every manager has filled the league's configured squad size: lineup plus bench.

The commissioner can arrange the draft order before it starts. If no complete custom order is set, the order is randomized when the draft starts. The initial waiver queue is the reverse of the draft order.

## Auto Picks

If your clock expires, Draft Fantasy selects the first valid player in your auto-pick list. If none is valid, it selects the highest-rated valid player. You can also use the auto-pick list as a shortlist during the draft.

With standard pick times of five minutes or less, a manager who has been offline for five minutes is fast-tracked to an automatic pick. Custom slow drafts over five minutes keep the full pick time. The commissioner can also end the current turn with `Force Pick`, which uses the same auto-pick rules.

## League Admin

The league admin section is located at the top of the draft page. It will only be visible to the league admin.

* League admin can end a user's turn before the timer runs out, by clicking "Force Pick" in the admin section at the top of the draft page.
* League admin can pause the draft.
* League admin can restart the draft.
* League admin can change the draft order before the draft starts.
