## Download Players

You can download a CSV spreadsheet of players from `/api/players/csv` on the domain for the competition you play. For example, Premier League uses [https://app.draftfantasy.com/api/players/csv](https://app.draftfantasy.com/api/players/csv).

Add `?leagueId=<LEAGUE_ID>` to calculate the exported points using that league's custom scoring.

## League and draft data

League and draft data is available in JSON format via our [API](/essentials/api). To convert the data to CSV, you can use a tool like [JSON to CSV](https://www.convertcsv.com/json-to-csv.htm).
